# SplitClo

**顏值時鐘 · Chill · Landscape Only**

A refined, atmospheric digital clock designed exclusively for landscape orientation on mobile.  
Soft ambient orbs, fluid digit transitions, second progress ring, and local music playback.

---

### Features

- **Landscape-only** — Portrait shows a gentle rotate prompt
- **Force fullscreen** — Tap anywhere to enter immersive mode
- **Local music** — Upload any audio file from your device and play while viewing the clock
- **Chill atmosphere** — Soft floating orbs, noise texture, purple/indigo ambient glow
- **Smoother motion** — Spring digit flips with blur, continuous second ring, breathing colon
- **Thicker type** — Geist weight 600 for a more present feel
- **Auto-hiding controls** — Minimal pill that fades when idle
- **Reduced-motion** friendly
- Pure HTML / CSS / JS — zero dependencies
- MIT License

---

### How to use

1. Open on a phone (or browser device toolbar)
2. Rotate to **landscape**
3. Tap anywhere → enters fullscreen
4. Tap the music icon → choose a local song
5. Enjoy the chill clock

GitHub Pages / any static host works out of the box.

---

### Design notes

- Typography: Geist (600) + JetBrains Mono
- Motion: spring curves, low-frequency ambient floats, continuous second progress
- Palette: near-black with soft violet / indigo orbs
- Controls use backdrop-blur glass pill for a native feel
