# SplitClo

**顏值時鐘 · Landscape Only**

A refined, minimal digital clock designed exclusively for landscape orientation on mobile.  
Turn your phone sideways to reveal a clean split aesthetic timepiece.

---

### Features

- **Landscape-only** — Portrait shows a gentle rotate prompt
- **Split visual frame** with soft dual panels
- **Fluid digit transitions** on minute/hour change
- **Subtle second indicator** + live date
- **Reduced-motion** friendly
- Pure HTML / CSS / JS — zero dependencies
- MIT License

---

### Demo

Open `index.html` on a phone (or use browser device toolbar in landscape).

GitHub Pages / any static host works out of the box.

---

### Design notes

- Typography: Geist + JetBrains Mono
- Motion follows restraint principles (no high-frequency animation, spring-like digit flips, colon pulse only)
- Dark, near-black base with low-contrast split for visual quietness
- Optimized for mobile landscape aspect ratios
